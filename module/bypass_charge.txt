# 旁路供电会优先探测并启用设备提供的硬件旁路节点。
# 程序只使用名称明确包含 bypass 的专用节点，并在写入后读取验证。
# 退出旁路时会恢复节点原值。

# 如果设备没有可验证的硬件旁路节点，程序会自动使用 500mA 兼容模式。
# 部分设备可能忽略过低电流，500mA 是较常见的最低有效值。

# 使用方法：
# 一行一个 APP 包名
# 打开对应 APP 时会进入旁路供电；熄屏、离开应用或关闭功能后退出。
# 空行和以 # 开头的行会被忽略。

# 示例：
# com.tencent.tmgp.sgame
# com.miHoYo.Yuanshen
# com.hypergryph.arknights

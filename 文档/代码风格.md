# 代码风格.md
旨在让ai更熟悉我的代码风格，以输出更好的内容

## 指针方面
1. **统一清理** — 用 `goto cleanup` 把资源释放集中到一处，只写一次 `return NULL`。
2. **哨兵 NULL** — 返回数组或链表时末尾置 NULL，省去长度参数。
3. **打包结构体** — 用结构体封装“指针+配套信息”，只返回一个值。
4. **宏消灭重复** — 用宏检查资源，自动跳转清理，省去手写 `if (!ptr) return NULL`。
5. **避免二级指针** — 尽量用返回值代替 `void**` 出参，调用方直接赋值。
6. **变量声明进 `if`** — C99 起 `if (TYPE x = func(); !x)`，省一行。
7. **用 `exit`/`pthread_exit`** — 工具程序直接退出，不层层传错误指针。

## 定时任务方面
轻任务只触发一次的定时任务，可以用sleep，cron
但是一些需要不断轮询的，想要降低开销，就得使用timerfd+epoll，或者epollwait

## 配置文件变化
最优的话选择用inotify监听事件变化，其次用mtime
用usleep（500 * 1000）解决IN_MODIFY的重复事件，也就是防抖

## 其他
如果用了int就不要用指针，因为int才4字节，用了指针就8字节了
如果确保了基本不可能出现错误，那可以省略错误返回，节省代码
尽量用线程取代进程
